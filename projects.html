DEPLOYED FOR DELIVERAIL

EMMA, AI Voice Receptionist

A voice agent that handles reception calls end to end, fully on device, for a logistics company.

  • Speech to text with faster-whisper, reasoning through a local Ollama LLM, speech out with Coqui TTS.
  • Request validation and a knowledge grounding check run in plain Python before the LLM is invoked.
  • The model can only answer from RAG grounded knowledge or trigger a live shipment booking through tool calls.
STACK
Python, faster-whisper, Ollama, Coqui TTS
STATUS
Contracted and deployed for Deliverail
NETWORK
Zero external API calls, fully offline
COST
Zero per request cost

Kuro, Local Multi Agent Assistant

A private, fully offline AI assistant where every assistant has its own knowledge base, prompt and settings.

  • Answers from PDF, DOCX, TXT, CSV and Excel with streamed, cited responses and a confidence score.
  • Hybrid retrieval combining FAISS and keyword search with reranking, plus a voice interface.
  • CSV and Excel analytics with KPI reporting, user accounts, and backup and restore.
STACK
React, FastAPI, Ollama, FAISS
STATUS
Demoed and stress tested with CMR University faculty and students
NETWORK
Runs locally through Ollama

CareerOS, Autonomous Job Search

A personal AI command center that runs my job search across ten live product sections.

  • Syncs and classifies job emails with the Gmail API, pulls roles from Adzuna and scores matches against my resume.
  • Tracks every application through a pipeline, interview prep and recruiter follow ups.
  • Every AI suggested action needs explicit confirmation before anything is sent or written. No scraping or ToS violating automation.
STACK
Next.js, React, TypeScript, Prisma, PostgreSQL, Ollama
TESTS

FEATURE
